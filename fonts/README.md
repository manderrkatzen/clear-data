# Source Sans 3

The locally served Latin variable WOFF2 is Source Sans 3 by Adobe, downloaded from
Google Fonts: https://fonts.gstatic.com/s/sourcesans3/v20/nwpStKy2OAdR1K-IwhWudF-R3w8aZQ.woff2

Source project and SIL Open Font License: https://github.com/adobe-fonts/source-sans

This font is self-hosted so the workspace does not depend on a third-party font
request. Characters outside the Latin subset fall back to the browser's sans-serif.
